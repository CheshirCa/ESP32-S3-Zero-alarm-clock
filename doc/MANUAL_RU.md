## Подключение Оборудования

### Необходимые Компоненты

| Компонент | Характеристики | Количество |
|-----------|---------------|-----------|
| Плата ESP32-S3 | Любой модуль ESP32-S3 | 1 |
| OLED Дисплей | 128x64 I2C SSD1306, 0.96" | 1 |
| Датчик температуры | AHT20 (I2C) | 1 |
| Датчик давления | BMP280 (I2C) | 1 |
| Зуммер | Пассивный или активный | 1 |
| RGB Светодиод | WS2812B или отдельные R/G/B | 1 |
| Кнопка | Нормально разомкнутая | 1 |
| Резисторы | 10 кОм подтяжка для кнопки | 1 |
| Питание | 5V USB или DC | 1 |

### Схема Подключения

```
Подключение выводов ESP32-S3:

Дисплей (I2C OLED SSD1306):
  SDA (GPIO 10) ────────► SDA дисплея
  SCL (GPIO 11) ────────► SCL дисплея
  3.3V ─────────────────► VCC дисплея
  GND ──────────────────► GND дисплея

Датчики (I2C):
  SDA (GPIO 10) ────────► AHT20 SDA ────► BMP280 SDA
  SCL (GPIO 11) ────────► AHT20 SCL ────► BMP280 SCL
  3.3V ─────────────────► VCC датчиков
  GND ──────────────────► GND датчиков

Зуммер:
  GPIO 12 ──────────────► Зуммер (+)
  GND ──────────────────► Зуммер (-)
  
RGB Светодиод (WS2812B):
  GPIO 21 ──────────────► LED DIN
  5V ───────────────────► LED VCC
  GND ──────────────────► LED GND

Кнопка:
  GPIO 0 (BOOT) ────┬───► Контакт кнопки 1
  GND ──────────────┴───► Контакт кнопки 2
  (Внутренняя подтяжка включена)
```

### Проверка I2C Адресов

После подключения датчиков проверьте их I2C адреса:

**Ожидаемые адреса:**
- AHT20: `0x38`
- BMP280: `0x76`

Проверить можно в Serial консоли после первой загрузки - устройство сообщит о статусе датчиков.

## Установка Программного Обеспечения

### Шаг 1: Установка Arduino IDE

1. Скачайте Arduino IDE с https://www.arduino.cc/en/software
2. Установите версию 2.0 или новее (рекомендуется)

### Шаг 2: Добавление Поддержки ESP32

1. Откройте Arduino IDE
2. Перейдите **Файл → Настройки**
3. В поле "Дополнительные ссылки для Менеджера плат" добавьте:
```
https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
```
4. Перейдите **Инструменты → Плата → Менеджер плат**
5. Найдите "esp32"
6. Установите "esp32 by Espressif Systems" (версия 2.0.0 или новее)

### Шаг 3: Установка Необходимых Библиотек

Откройте **Инструменты → Управление библиотеками** и установите:

```
Название библиотеки      | Версия   | Автор
-------------------------|----------|------------------
U8g2                     | 2.35.x   | oliver
Adafruit AHTX0           | 2.0.x    | Adafruit
Adafruit BMP280 Library  | 2.6.x    | Adafruit
Adafruit NeoPixel        | 1.12.x   | Adafruit
ArduinoJson              | 6.21.x   | Benoit Blanchon
```

**Шаги установки для каждой библиотеки:**
1. Нажмите значок "Менеджер библиотек" (книги) на левой панели
2. Найдите название библиотеки
3. Нажмите "Установить"
4. Дождитесь завершения загрузки и установки

### Шаг 4: Настройка Параметров Платы

1. Подключите ESP32-S3 к компьютеру через USB
2. В Arduino IDE выберите:
   - **Плата:** "ESP32S3 Dev Module"
   - **Скорость загрузки:** 921600
   - **USB Mode:** "Hardware CDC and JTAG"
   - **USB CDC On Boot:** "Enabled"
   - **Partition Scheme:** "Huge APP (3MB No OTA/1MB SPIFFS)"
   - **Порт:** Выберите порт ESP32-S3 (например, COM3 в Windows, /dev/ttyUSB0 в Linux)

### Шаг 5: Настройка Параметров Оборудования в Коде

Перед загрузкой проверьте конфигурацию выводов в `ESP32-S3-Z-Clock.ino`:

```cpp
// Строки 25-33: Определения выводов
#define BOOT_PIN 0           // Вывод кнопки (BOOT)
#define BUZZER_PIN 12        // Управление зуммером
#define WS2812_PIN 21        // Данные RGB светодиода
#define SDA_PIN 10           // I2C данные (дисплей + датчики)
#define SCL_PIN 11           // I2C тактирование

// Строки 20-23: Тип зуммера
#define BUZZER_TYPE BUZZER_PASSIVE  // Измените на BUZZER_ACTIVE если нужно
#define LOW_LEVEL_TRIGGER 1         // 1 для LOW триггера, 0 для HIGH
```

**Если ваша разводка отличается, измените эти номера выводов!**

### Шаг 6: Загрузка Прошивки

1. Откройте `ESP32-S3-Z-Clock.ino` в Arduino IDE
2. Нажмите **Скетч → Проверить/Компилировать** (Ctrl+R)
3. Дождитесь завершения компиляции (может занять 1-2 минуты)
4. При успехе нажмите кнопку **Загрузить** (→)
5. Дождитесь загрузки (30-60 секунд)
6. Ищите сообщение "Загрузка завершена"

**Если загрузка не удалась:**
- Попробуйте удерживать кнопку BOOT во время загрузки
- Проверьте USB кабель (используйте кабель передачи данных, а не только для зарядки)
- Проверьте правильность выбора порта
- Попробуйте другой USB порт на компьютере

### Шаг 7: Первая Загрузка

1. Откройте **Инструменты → Монитор порта** (Ctrl+Shift+M)
2. Установите скорость: **115200**
3. Установите окончание строки: **Новая строка**
4. Нажмите кнопку RESET на ESP32-S3
5. Вы должны увидеть сообщения запуска:

```
Инициализация...
NVS инициализирована OK
WiFi SSID: Enter_SSID
ВНИМАНИЕ: Используются настройки WiFi по умолчанию!
Настройте WiFi через Serial команды или веб-интерфейс
Инициализация датчиков...
AHT20: OK (0x38 на Wire1)
BMP280: OK (прямой доступ)
Настройка завершена!
> 
```

## Первоначальная Настройка

### Метод 1: Режим Настройки (Самый Простой - Рекомендуется)

**Подходит для:** Первоначальной настройки, компьютер не требуется

**Шаги:**

1. **Вход в Режим Настройки:**
   - Во время запуска устройства (первые 5 секунд), нажмите и удерживайте кнопку BOOT
   - Удерживайте **10 секунд**, пока светодиод не загорится фиолетовым
   - Дисплей покажет: "SETUP MODE"
   - Отпустите кнопку

2. **Подключение к WiFi Настройки:**
   - На телефоне/компьютере откройте настройки WiFi
   - Подключитесь к сети: `ESP32-Clock-Setup`
   - Пароль: `12345678`

3. **Открытие Страницы Настройки:**
   - Откройте веб-браузер
   - Перейдите по адресу: `http://192.168.4.1`
   - Вы должны увидеть интерфейс настройки:

```
┌─────────────────────────────────────┐
│  Настройка Умных Часов ESP32-S3     │
├─────────────────────────────────────┤
│                                     │
│  Конфигурация WiFi                  │
│  ┌────────────────────────────┐    │
│  │ SSID: [МояДомашняяСеть   ] │    │
│  └────────────────────────────┘    │
│  ┌────────────────────────────┐    │
│  │ Пароль: [**********      ] │    │
│  └────────────────────────────┘    │
│                                     │
│  Язык                               │
│  ( ) English  (•) Русский          │
│                                     │
│  ┌──────────────────────┐          │
│  │  Сохранить и         │          │
│  │  Перезагрузить       │          │
│  └──────────────────────┘          │
│                                     │
└─────────────────────────────────────┘
```

4. **Ввод Учетных Данных WiFi:**
   - Введите имя вашей WiFi сети в поле SSID
   - Введите пароль WiFi
   - Выберите предпочитаемый язык
   - Нажмите "Сохранить и Перезагрузить"

5. **Перезагрузка Устройства:**
   - Подождите 10-15 секунд
   - Устройство подключится к вашей WiFi
   - Дисплей покажет IP адрес
   - Светодиод загорится синим (WiFi подключен)

### Метод 2: Serial Консоль (Расширенный)

**Подходит для:** Разработчиков, автоматизации, настройки без дисплея

**Шаги:**

1. **Открытие Serial Консоли:**
   - Arduino IDE: **Инструменты → Монитор порта**
   - PuTTY (Windows): Порт COM3, Скорость 115200
   - screen (Linux/Mac): `screen /dev/ttyUSB0 115200`

2. **Ожидание Приглашения:**
   ```
   Настройка завершена!
   > _
   ```

3. **Настройка WiFi:**
   ```
   > WIFI SET МояДомашняяСеть МойПароль
   Настройки WiFi обновлены:
   WiFi SSID: МояДомашняяСеть
   Пароль: **********
   
   Подключение к WiFi...
   .....
   WiFi подключен успешно!
   IP адрес: 192.168.1.100
   
   Используйте команду SAVE для сохранения настроек в NVS
   > 
   ```

4. **Сохранение Настроек:**
   ```
   > SAVE
   Сохранение настроек в NVS...
     - Конфигурация WiFi сохранена
     - Настройки дисплея сохранены
     - Настройки мелодий сохранены
   Все настройки успешно сохранены!
   > 
   ```

5. **Опционально - Установка Языка:**
   ```
   > LANGUAGE RU
   Язык изменен на: Русский
   Настройки сохранены. Перезагрузитесь для применения изменений в стартовых сообщениях.
   > 
   ```

### Метод 3: Ручная Настройка в Коде (Не Рекомендуется)

**Используйте только если другие методы недоступны**

1. Отредактируйте `ESP32-S3-Z-Clock.ino`
2. Найдите строки 54-55:
   ```cpp
   String defSSID = "Enter_SSID";
   String defPASS = "Enter_Pass";
   ```
3. Измените на вашу WiFi сеть:
   ```cpp
   String defSSID = "МояДомашняяСеть";
   String defPASS = "МойПароль";
   ```
4. Повторно загрузите прошивку

**Примечание:** Это жестко кодирует учетные данные в прошивке - небезопасно для публичного кода!

### Вкладка Настройки - Конфигурация Времени

Нажмите **Настройки** → **Время** для настройки времени и даты:

```
┌─────────────────────────────────────────────────┐
│  ⏱ Настройки Времени                            │
├─────────────────────────────────────────────────┤
│                                                  │
│  NTP Сервер                                      │
│  ┌──────────────────────────────────────┐      │
│  │ pool.ntp.org                         │      │
│  └──────────────────────────────────────┘      │
│  Популярные серверы: time.google.com,           │
│                     time.cloudflare.com         │
│                                                  │
│  Часовой пояс (смещение от GMT)                 │
│  ┌────┐ часов                                   │
│  │ +3 │ (GMT+3 = Москва, GMT-5 = Нью-Йорк)     │
│  └────┘                                         │
│                                                  │
│  Летнее время (DST)                             │
│  ┌────┐ часов                                   │
│  │  0 │ (0 = нет DST, +1 = летнее время)       │
│  └────┘                                         │
│                                                  │
│  Ручная установка времени                       │
│  ┌──────┐  ┌──────┐  ┌──────┐                 │
│  │ 2026 │  │  01  │  │  25  │                 │
│  └──────┘  └──────┘  └──────┘                 │
│   Год      Месяц      День                      │
│                                                  │
│  ┌────┐ : ┌────┐ : ┌────┐                     │
│  │ 12 │   │ 34 │   │ 56 │                     │
│  └────┘   └────┘   └────┘                     │
│  Час       Мин       Сек                        │
│                                                  │
│  ┌──────────────┐  ┌──────────────┐           │
│  │Синхр. ⏱     │  │Сохранить ✓   │           │
│  └──────────────┘  └──────────────┘           │
│                                                  │
│  ⓘ Время синхронизируется автоматически        │
│     каждые 6 часов                              │
│                                                  │
└─────────────────────────────────────────────────┘
```

**Описание полей:**

- **NTP Сервер:** Сервер для автоматической синхронизации времени
  - По умолчанию: `pool.ntp.org`
  - Альтернативы: `time.google.com`, `time.cloudflare.com`, `time.nist.gov`
  
- **Часовой пояс:** Ваше смещение от GMT
  - Примеры: GMT+3 (Москва), GMT-5 (Нью-Йорк), GMT+1 (Берлин)
  - Диапазон: от -12 до +14 часов
  
- **DST:** Дополнительное смещение для летнего времени
  - 0 = Нет DST
  - +1 = Летнее время (наиболее распространено)
  - Применяется автоматически, без переключения по датам
  
- **Ручная установка времени:** Переопределить NTP время (временно до следующей NTP синхронизации)
  - Используйте только если NTP недоступен
  - Формат: ГГГГ-ММ-ДД ЧЧ:ММ:СС

**Примеры сценариев:**

1. **Москва (без DST):**
   - Часовой пояс: +3
   - DST: 0

2. **Нью-Йорк (с DST):**
   - Часовой пояс: -5 (EST)
   - DST: +1 (EDT летом)

3. **Токио (без DST):**
   - Часовой пояс: +9
   - DST: 0

## Руководство по Serial Консоли

### Открытие Serial Консоли

**Arduino IDE:**
1. **Инструменты → Монитор порта** (Ctrl+Shift+M)
2. Установите скорость: **115200**
3. Установите окончание строки: **Новая строка**

**PuTTY (Windows):**
1. Тип подключения: **Serial**
2. Serial line: **COM3** (проверьте в Диспетчере устройств)
3. Скорость: **115200**
4. Нажмите **Open**

**screen (Linux/Mac):**
```bash
screen /dev/ttyUSB0 115200
```

**minicom (Linux):**
```bash
minicom -D /dev/ttyUSB0 -b 115200
```

## Управление WiFi

### Сравнение Режимов WiFi

| Функция | Всегда ВКЛ | Умный WiFi |
|---------|-----------|------------|
| **Энергопотребление** | ~130мА | ~80мА средн |
| **Доступ к Web** | Мгновенно | 2-5 сек задержка при первом запросе |
| **Синхр. NTP** | Каждые 6 часов | Каждые 6 часов (авто пробуждение) |
| **Погода** | Каждый час | Каждый час (авто пробуждение) |
| **Ручное управление** | Не требуется | Можно включить на 10 мин через кнопку |
| **Подходит для** | Настенное питание | Батарейное питание |

### Поведение Умного WiFi

**WiFi включается когда:**
1. Требуется синхр. NTP (настраиваемо, по умолчанию 6 часов)
2. Требуется обновление погоды (настраиваемо, по умолчанию 1 час)
3. Получен веб-запрос (остается включенным 10 минут)
4. Ручное включение (удержание кнопки 3+ сек или команда `wifi on`)

**WiFi выключается когда:**
1. 10 минут бездействия (настраиваемо)
2. Все запланированные задачи выполнены

**Лог активности в консоли:**

## Ночной Режим

### Работа Ночного Режима

Ночной режим автоматически:
1. Снижает яркость дисплея в указанное время начала
2. Восстанавливает нормальную яркость в указанное время окончания
3. Может быть временно отключен нажатием кнопки BOOT

### Временной Диапазон Через Полночь

Ночной режим правильно обрабатывает временные диапазоны через полночь:

**Пример: с 11 вечера до 7 утра**
- Активен с 23:00 Дня 1 до 07:00 Дня 2
- Не активен с 07:00 до 23:00

**Логика:**
```
Текущее время в диапазоне если:
  (текущее >= начало) ИЛИ (текущее < конец)
```

#### Отправка Serial Команды

```python
import serial
import time

def send_command(port, command):
    """Отправить команду часам ESP32"""
    ser = serial.Serial(port, 115200, timeout=1)
    time.sleep(2)  # Ждем инициализации serial
    
    ser.write(f"{command}\n".encode())
    
    # Читаем ответ
    time.sleep(0.5)
    response = ser.read_all().decode()
    
    ser.close()
    return response

# Примеры
print(send_command('/dev/ttyUSB0', 'STATUS'))
print(send_command('/dev/ttyUSB0', 'ALARM SET 0 07:30 Утро'))
print(send_command('/dev/ttyUSB0', 'TIMER 15:00 Чай'))
```

#### Мониторинг Вывода Serial

```python
import serial

def monitor_serial(port):
    """Мониторинг вывода serial ESP32 для событий"""
    ser = serial.Serial(port, 115200, timeout=1)
    
    print("Мониторинг часов ESP32...")
    
    while True:
        if ser.in_waiting > 0:
            line = ser.readline().decode().strip()
            print(f"Получено: {line}")
            
            # Обнаружить срабатывание будильника
            if '[Будильник]' in line and 'сработал' in line.lower():
                print("🔔 СРАБОТАЛ БУДИЛЬНИК!")
                # Запустить действие здесь
                
            # Обнаружить истечение таймера
            if '[Таймер]' in line and 'истек' in line.lower():
                print("⏰ ТАЙМЕР ИСТЕК!")
                # Запустить действие здесь

monitor_serial('/dev/ttyUSB0')
```

**Проблема: Нет звука от зуммера**

   ```cpp
   #define BUZZER_TYPE BUZZER_PASSIVE  // или BUZZER_ACTIVE
   ```

3. Полярность зуммера

**Проблема: Неправильная высота тона/нет мелодии (только сигналы)**

## Примеры Использования

### Случай 1: Система Умного Пробуждения

**Цель:** Постепенное пробуждение со светом и будильником

**Настройка:**
1. Установите будильник ESP32 на 7:00
2. Настройте автоматизацию Home Assistant:
   ```yaml
   automation:
     - alias: "Постепенное Пробуждение"
       trigger:
         - platform: time
           at: "06:50:00"
       action:
         - service: light.turn_on
           entity_id: light.bedroom
           data:
             brightness: 10
         - delay: '00:05:00'
         - service: light.turn_on
           entity_id: light.bedroom
           data:
             brightness: 100
   ```
3. Будильник ESP32 срабатывает в 7:00 (свет уже на 100%)

### Случай 2: Таймер Готовки с Уведомлением

**Цель:** Получать уведомление на телефон при истечении таймера готовки

**Настройка:**
1. Запустите таймер на ESP32:
   ```
   > timer 15:00 Пицца
   ```

2. Мониторьте с помощью Python скрипта:
   ```python
   # monitor_timer.py
   import serial
   import requests
   
   ser = serial.Serial('/dev/ttyUSB0', 115200)
   
   while True:
       line = ser.readline().decode()
       if 'Таймер' in line and 'истек' in line:
           # Отправить на телефон через Pushover
           requests.post('https://api.pushover.net/1/messages.json', data={
               'token': 'APP_TOKEN',
               'user': 'USER_KEY',
               'message': 'Пицца готова!'
           })
   ```

### Случай 3: Энергосберегающая Метеостанция

**Цель:** Метеостанция на батарейках с длительным временем работы

**Настройка:**
1. Включите режим Умный WiFi:
   ```
   > wifi smart
   > save
   ```

2. Настройте длинные интервалы через веб-интерфейс:
   - Синхр. NTP: Каждые 12 часов (720 мин)
   - Обновление погоды: Каждые 2 часа (120 мин)
   - Автовыкл: 5 минут

3. Включите ночной режим:
   ```
   > night on 22:00-08:00 5
   > save
   ```

**Результат:** ~50% экономии энергии, хватит на 2-3 дня от батареи

### Случай 4: Расписание Будильников Для Работы

**Цель:** Разные будильники для разных дней

**Настройка:**
```
# Ранняя смена (Пн, Ср, Пт)
> alarm set 0 135 06:00 Ранняя смена R S

# Поздняя смена (Вт, Чт)
> alarm set 1 24 08:00 Поздняя смена R S

# Будильник выходного дня (Сб, Вс)
> alarm set 2 67 09:00 Выходной R S

# Обеденный перерыв (Пн-Пт)
> alarm set 3 12345 12:30 Обед R S

> alarm list
(Проверьте все будильники)

> save
```

### Коды Ошибок

В настоящее время нет формальных кодов ошибок. Ошибки сообщаются как текстовые сообщения.

Распространенные сообщения об ошибках:
- "Не удалось подключиться к WiFi!" - Невозможно подключиться к сети
- "Ошибка синхр. времени!" - NTP сервер недоступен
- "Недопустимый индекс" - Индекс будильника вне диапазона (0-9)
- "Не удалось записать NVS" - Хранилище заполнено или аппаратная проблема

### Глоссарий

- **NTP** - Network Time Protocol, для синхронизации времени
- **NVS** - Non-Volatile Storage, для постоянных настроек
- **DST** - Daylight Saving Time, смещение летнего времени
- **GMT** - Greenwich Mean Time (UTC+0)
- **I2C** - Inter-Integrated Circuit, последовательный протокол для датчиков
- **SPI** - Serial Peripheral Interface (не используется в этом проекте)
- **PWM** - Pulse Width Modulation, для тонов зуммера
- **RSSI** - Received Signal Strength Indicator, качество сигнала WiFi
- **WS2812B** - Тип RGB светодиодной ленты
- **Пассивный зуммер** - Требует сигнал PWM, может играть мелодии
- **Активный зуммер** - Только вкл/выкл, одна частота
